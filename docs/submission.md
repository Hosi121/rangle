# DevFest Hackathon 2026 提出用リポジトリ

運営の初期READMEから提出条件を要約した記録。開発と提出は別のリポジトリを使う。

| 用途 | リポジトリ |
| --- | --- |
| 開発正本（origin） | [Hosi121/rangle](https://github.com/Hosi121/rangle) |
| 最終提出（submission） | [Devfest-Hackathon-2026/df-2026-t002](https://github.com/Devfest-Hackathon-2026/df-2026-t002) |

## はじめに

招待は7日以内に受諾する。期限切れ・メンバー変更は運営へ連絡する。提出先はpublicで、開催中も運営・審査員・参加者が閲覧できる。

## 開発用のリポジトリは別に作ることをおすすめします

提出先ではGitHub Actions/Pagesを使えない。開発用でCI・配備を行い、最終版のコード・資料と作品URLを期限までに提出先へ反映する。開発用にしかない内容は審査対象にならない。

## 秘密情報をコミットしない

API key・password・SA keyはコミットしない。履歴ごとの反映でも過去の秘密が公開される。誤公開時は鍵を無効化・再発行して運営へ連絡し、履歴削除だけで済ませない。push protectionで止められた鍵はコミットから外す。

## 提出

締切・方法は運営案内に従う。期限後は提出先がread-onlyになり、pushできなくなる。

## ライセンス

提出先の初期設定は[MIT](../LICENSE)。外部素材の条件は個別に保持する。
